# Vrinda Store Data Analysis – Excel Project

## Project Overview
This project focuses on analyzing the Vrinda Store dataset using Microsoft Excel. The goal is to understand sales performance, customer behavior, and order trends through data analysis and visualization.

## Objectives
- Analyze overall sales and order performance.
- Understand customer purchasing patterns.
- Identify sales trends across different categories.
- Compare sales performance using charts and Pivot Tables.
- Present meaningful insights to support business decisions.

## Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Charts and Data Visualization
- Data Cleaning and Analysis

## Key Analysis
- Sales and order analysis
- Customer gender analysis
- Order status analysis
- Sales distribution across different channels
- Monthly sales trends

## Skills Demonstrated
- Data Analysis
- Data Cleaning
- Pivot Table Creation
- Data Visualization
- Business Insights Generation

## Project Outcome
This project helped me practise Excel-based data analysis and understand how business data can be converted into useful insights for decision-making.

Dataset used: Vrinda Store Dataset
